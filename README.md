# Ahadu Center

A unified multi-module platform featuring:
- **Movie Center:** Browse, request, and stream information about movies.
- **Electronics Hub:** E-commerce shop with product comparisons, cart, and checkout.
- **Book Center:** Library system supporting book purchases, reservations, and borrowings.
- **Admin Panel:** Complete management system for products, movies, books, users, and orders.

## Tech Stack
- **Frontend:** React (Vite), Redux Toolkit, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT Auth

## Project Structure
```text
ahadu-center/
├── client/     # React Frontend (Vite)
```
